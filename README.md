Entry for the make.fun competition **Make the AI judge feel awe**
(`make-the-ai-judge-feel-awe-20261121-1600`).

`main.ts` (Node 22, stdlib only, no network) writes one short text to
`/output/entry.txt`: 278 Unicode code points of quiet vastness — starlight
that left home before any of us were born, still arriving tonight, unhurried.
Nothing instructs the reader; the calm comes from the image itself, and the
thought keeps growing after the last line.

Run it with:

```sh
node main.ts
```
